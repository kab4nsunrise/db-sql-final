 Описание проекта: Сервис отслеживания посылок

 Общее описание

Сервис отслеживания посылок — это бэкенд-приложение на Go, реализующее полноценный CRUD для управления информацией о почтовых отправлениях. Данные хранятся в реляционной базе данных SQLite. Приложение позволяет регистрировать новые посылки, просматривать список отправлений конкретного клиента, изменять статус и адрес доставки, а также удалять посылки (при условии, что они ещё не отправлены). Проект демонстрирует навыки работы с базами данных, написания SQL-запросов, интеграционного тестирования и обработки бизнес-логики на Go.

 Основной функционал

- Регистрация посылки – создание новой записи в БД с начальным статусом «зарегистрирована» (registered). Трек-номер автоматически присваивается как идентификатор записи.
- Получение списка посылок клиента – выборка всех отправлений по идентификатору клиента.
- Изменение статуса посылки – обновление статуса на один из трёх: `registered` (зарегистрирована), `sent` (отправлена), `delivered` (доставлена).
- Изменение адреса доставки – разрешено только для посылок в статусе `registered`.
- Удаление посылки – разрешено только для посылок в статусе `registered`.

 Архитектура проекта

Проект состоит из следующих ключевых компонентов:

- Основной пакет (`main`) – инициализирует подключение к БД, создаёт экземпляр `ParcelStore` и `ParcelService`, запускает проверочные сценарии (вывод списка посылок и т.п.).
- Пакет `parcel` – содержит:
  - Интерфейс `ParcelStore` (описывает методы работы с БД).
  - Реализацию `ParcelService`, которая инкапсулирует бизнес-логику и вызывает методы хранилища.
  - Реализацию `ParcelStore` для SQLite (функции `Create`, `ReadAll`, `UpdateStatus`, `UpdateAddress`, `Delete`).
  - Константы статусов: `ParcelStatusRegistered`, `ParcelStatusSent`, `ParcelStatusDelivered`.
- Тесты – интеграционные тесты (`parcel_test.go`), проверяющие корректность работы всех методов хранилища и сервиса.

 Технологии и инструменты

- **Язык:** Go (стандартная библиотека, пакеты `database/sql`, `testing`).
- **СУБД:** SQLite (драйвер `modernc.org/sqlite` или аналогичный).
- **Структура БД:** таблица `parcel` с полями:
  - `number` – автоинкрементный первичный ключ (трек-номер).
  - `client` – идентификатор клиента (целое число).
  - `status` – текущий статус (строка).
  - `address` – адрес доставки (строка).
  - `created_at` – дата и время создания (строка в формате ISO).

 Цели проекта

- Отработка практических навыков взаимодействия с реляционной БД через Go.
- Реализация бизнес-логики с учётом ограничений по статусам.
- Написание интеграционных тестов для проверки всех операций с БД.
- Демонстрация умения читать и дополнять готовый каркас приложения.

 Запуск и тестирование

1. Убедитесь, что файл БД `tracker.db` существует (или будет создан автоматически).
2. Выполните команду `go test .` для запуска интеграционных тестов – все они должны завершиться успешно.
3. Запустите приложение командой `go run .` – в консоль будет выведен список посылок (при их наличии) и другая отладочная информация.
